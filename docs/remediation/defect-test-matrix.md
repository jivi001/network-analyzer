## Matrix Legend
- **Baseline Status:**
  - `CONFIRMED_FAILING`: Defect directly verified by a failing test in baseline pytest run.
  - `CONFIRMED_STATIC`: Defect verified by code inspection, static analysis, or compiler/type checker.
  - `CONFIRMED_ARCH`: Architectural, concurrency, or lifecycle defect verified through runtime trace or code audit.
- **Verification Status:**
  - `VERIFIED_RESOLVED`: Minimal fix implemented and verified by automated regression tests.
  - `FIXED_PENDING_VERIFICATION`: Fix implemented, awaiting independent QA/security gate acceptance.
  - `UNRESOLVED`: Defect verified, awaiting scheduled phase gate to begin implementation.
  - `NOT_A_DEFECT`: Investigated and confirmed to be a false positive.
